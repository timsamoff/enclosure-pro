# Enclosure Pro

A cross-platform precision layout tool for guitar pedal enclosures.

Created by Tim Samoff ([@circuitous.fx](https://www.instagram.com/circuitous.fx/))

<img  src="https://github.com/timsamoff/enclosure-pro/blob/main/docs/fa-hand-holding-money.png?raw=true"  width="20px"  alt="Support This App!"> [Support This App!](https://ko-fi.com/circuitousfx)

## Features

* Centered grid lines

* Multi-side design views

* Drag-and-drop components

* Component footprint guides

* Metric/imperial units

* Print-ready blueprint export

## Download/Info

 - [Official Website](http://samoff.com/enclosure-pro)

## Development

After cloning, run `npm install`, then `npm run sentinel:install` to enable the repo's git hooks (commit checks live in `sentinel/`). `npm run electron:dev` starts the app.
