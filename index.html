Enclosure Pro

A cross-platform precision drill hole layout tool for effect pedal enclosures.

Created by Tim Samoff (@circuitous.fx)

Give Feedback Support This App! Try Circuit Scout!

Features

  • Centered grid lines
  • Multi-side design views
  • Drag-and-drop components
  • Component footprint guides
  • Metric/imperial units
  • Print-ready blueprint export
